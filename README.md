# 大模型训练：原理、系统与前沿

> 一门从零起点到研究前沿的系统课程：两学年 · 八学期 · 32 门课（G01–G32）+ 3 个研讨班（S1–S3）。
> 每门课：数学原理（结合工程视角）/ 论文与变迁史 / 动手作业 / 开放问题。
> 模式：讲义驱动、卡点生长——讲义铺路，读者的真实卡点回流为文档补丁；研讨班角色反转（读者主讲）。
> 终点标准与完整课程详表见[大纲.md](大纲.md)。

## 使用方法

1. 按序学习；工作急需的课题可插班先修（如 G26 的 attention 算子）；
2. 读法：逐段读懂，**卡住不需要组织成"问题"——把卡住的词或句子原样贴回**；
3. 每课的动手作业尽量完成（L2 的核心）；论文精读（L3 素材）按"变迁史"栏目顺藤摸瓜；
4. 每学期末综合检验：5 道跨课程大题，口头答辩式。

## 写作规范

- 每课的数学地基放 **§0 加油站**（按读者的卡点生长）；
- 公式：简单记号（如 6N、P0）用纯文本；带上下标/分式的行内数学用 `$...$`；成段推导用 `$$LaTeX$$` 块（GitHub / Obsidian / Typora / ZCode 聊天窗口均可渲染）；
- 术语首次出现当场给白话定义；关键数字给出处；
- 讲义统一模板（见[大纲](大纲.md)末节）；数学原理在可行处结合工程视角。
